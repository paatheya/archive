# Tension Distribution in Multi-Block String Systems

### 
In a suspended multi-block system connected by a single string
- **Bottom Segment:** Experiences the lowest tension because it only supports the weight of the lowest block 
- **Top Segment:** Experiences the highest tension because it must support the cumulative weight of all suspended blocks below it
### Key:
Tension at any point in a continuous suspended string is directly proportional to the total mass hanging beneath that point.
