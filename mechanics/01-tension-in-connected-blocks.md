# Tension Distribution in Multi-Block String Systems

### Mechanism:
In a vertical or suspended multi-block system connected by a single string/rope:
- **Bottom Segment:** Experiences the lowest tension because it only supports the weight of the lowest block ($T = m_{\text{bottom}} \cdot g$).
- **Top Segment:** Experiences the highest tension because it must support the cumulative weight of all suspended blocks below it ($T = \sum m \cdot g$).

### Key:
Tension at any point in a continuous vertical string is directly proportional to the total mass hanging beneath that point.
